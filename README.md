Minecraft proxy made in C++
currently just a localhost proxy without any additional features, this proxy is designed for enthusiasts who want to learn and tinker

first time setup:

set host server in config.json
Run auth.bat and follow the login instructions
run build.bat

after that just run start.bat and connect to localhost in game


usage:


{
  "proxy":  { "port": 25565 },
  "server": { "host": "your.server.net", "port": 25565 }
}


currently Windows only, later linux support will be added
